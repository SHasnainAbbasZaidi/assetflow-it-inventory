========================================================================
ASSETFLOW - UBUNTU HOSTING & DEPLOYMENT GUIDE
========================================================================

This guide explains how to host the AssetFlow backend (Node.js) and 
make the web UI and Android APK accessible on an Ubuntu production server.

Since the architecture has been updated, you NO LONGER need Flutter, Dart,
or Android Studio installed on your Ubuntu server. The server only needs 
Node.js.

========================================================================
STEP 1: PREREQUISITES ON UBUNTU
========================================================================
Connect to your Ubuntu server via SSH and install Node.js and PM2 
(a process manager to keep the app running in the background):

1. Update system packages:
   sudo apt update && sudo apt upgrade -y

2. Install Node.js (v20 recommended):
   curl -fsSL https://deb.nodesource.com/setup_20.x | sudo -E bash -
   sudo apt-get install -y nodejs

3. Install PM2 globally:
   sudo npm install -pm2 -g

========================================================================
STEP 2: COPYING FILES TO THE SERVER
========================================================================
You only need to copy the `server` folder to your Ubuntu machine. 
You do NOT need the `inventory_manager_flutter` folder on the server.

1. On your local machine, zip the `server` folder.
2. Transfer it to your Ubuntu machine (e.g., using SCP or FileZilla).
3. On Ubuntu, unzip the folder:
   unzip server.zip -d /var/www/assetflow
4. Navigate into the directory:
   cd /var/www/assetflow/server

========================================================================
STEP 3: INSTALL DEPENDENCIES & SETUP DATABASE
========================================================================
Inside the `/var/www/assetflow/server` directory on Ubuntu:

1. Install Node.js dependencies:
   npm install

2. Generate the Prisma Client for the database:
   npx prisma generate

(Note: The SQLite database file `dev.db` inside the `prisma` folder will
 automatically be used or created if it doesn't exist).

========================================================================
STEP 4: STARTING THE APP WITH PM2
========================================================================
To keep the app running even if you close the SSH terminal or the server
reboots:

1. Start the app:
   pm2 start src/server.js --name "assetflow"

2. Ensure PM2 starts on system boot:
   pm2 startup
   (Run the command that PM2 outputs on the screen)
   pm2 save

========================================================================
STEP 5: REVERSE PROXY WITH NGINX (RECOMMENDED)
========================================================================
By default, the app runs on port 555. It's recommended to use Nginx to
expose it to port 80 (HTTP) or 443 (HTTPS).

1. Install Nginx:
   sudo apt install nginx -y

2. Create a new configuration file:
   sudo nano /etc/nginx/sites-available/assetflow

3. Paste the following configuration (replace 'your_domain_or_IP' with your actual IP or domain):

   server {
       listen 80;
       server_name your_domain_or_IP;

       location / {
           proxy_pass http://localhost:555;
           proxy_http_version 1.1;
           proxy_set_header Upgrade $http_upgrade;
           proxy_set_header Connection 'upgrade';
           proxy_set_header Host $host;
           proxy_cache_bypass $http_upgrade;
       }
   }

4. Enable the configuration and restart Nginx:
   sudo ln -s /etc/nginx/sites-available/assetflow /etc/nginx/sites-enabled/
   sudo nginx -t
   sudo systemctl restart nginx

========================================================================
STEP 6: ACCESSING THE APP & ANDROID APK
========================================================================

- Web Interface: Open a browser and navigate to `http://your_domain_or_IP`
- Login Credentials: 
  Email: admin@assetflow.local
  Password: admin123

- Android App (APK): 
  When logged into the Web UI, look at the bottom of the left sidebar.
  There is a direct download link for the Android APK. Users can download 
  it directly to their phones from your Ubuntu server.

Note: When users install the APK, they must go to the "Settings" gear 
icon on the mobile app's login screen and enter your Ubuntu server's 
address (e.g., http://your_domain_or_IP) so the app knows where to connect!
