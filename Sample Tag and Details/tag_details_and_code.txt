==================================================
ASSET TAG SYSTEM SPECIFICATIONS & DESIGN CODE
==================================================

1. PERIPHERAL TAG (Smaller Tag)
--------------------------------------------------
Usage: Designed for peripheral devices such as keyboards, mice, headphones, monitor displays, etc.
Fields Included:
- Tag No: Format example -> keyboard - 4201 - (Date)
- Date Purchase: (Purchase Date)
Layout: Title at the top left, fields stacked vertically below. QR Code positioned on the top right.

2. PERSONNEL DEVICE DETAILS TAG (Bigger Tag)
--------------------------------------------------
Usage: Main hardware tag generated from application personnel data. 
Fields Included:
- Username:
- CPU:
- Motherboard:
- Storage:
- RAM:
- GPU:
Layout: Title at the top left, hardware specifications stacked vertically. QR Code positioned on the top right.

3. QR CODE SPECIFICATIONS & FUNCTIONALITY
--------------------------------------------------
Design: Standard QR code with the company/application logo placed directly in the center.
Functionality: By scanning the QR code, users/administrators can:
1. Add the device to the system.
2. Remove the device from the system.
3. See detailed information and specifications of the device.
